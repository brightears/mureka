## Genre Profiles

### Jazz Lounge / Cafe Jazz
- **Sub-genres**: Piano Trio, Cool Jazz, Bossa Nova, Swing
- **Moods**: warm, cozy, sophisticated, mellow, intimate
- **Tempo**: 80-108 BPM
- **Instruments**: piano, clean jazz guitar, upright bass, brushed drums
- **Use-case**: cafe, lounge, cocktail bar, restaurant
- **Negative**: no vocals, no synths, no electronic sounds

### French Cafe Music
- **Sub-genres**: Parisian musette accordion, French chanson style
- **Moods**: quietly sophisticated, warm and intimate, gently romantic
- **Tempo**: 68-76 BPM (slow jazz bossa)
- **Instruments**: acoustic bass pizzicato, soft musette accordion, nylon guitar fingerpicked
- **Use-case**: French cafe, boutique hotel, Parisian restaurant
- **Negative**: no vocals, no gypsy jazz, no Django, no manouche, no fast tempo
- **Key discovery**: "musette" is essential; acoustic bass pizzicato adds sophistication

### Bossa Nova Lounge
- **Sub-genres**: Brazilian jazz, modern lounge bossa, chillout bossa
- **Moods**: calm, welcoming, elegant, conversation-friendly
- **Tempo**: 88-100 BPM
- **Instruments**: nylon string guitar, upright bass, brushed drums, Rhodes piano
- **Use-case**: hotel lobby, cafe, upscale restaurant, wine bar
- **Negative**: no vocals, no harsh sounds, no heavy drums, no synths

### General Spa (spa-general)
- **Sub-genres**: Piano ambient, Nature ambient, Healing soundscape
- **Moods**: peaceful, serene, calming, nurturing, tranquil
- **Tempo**: 50-80 BPM
- **Instruments**: soft piano, gentle acoustic guitar, ambient pads, crystal singing bowls, tibetan bowls
- **Atmospheres**: misty morning, gentle rain, forest glade, flowing stream, zen garden
- **Use-case**: spa reception, treatment room, massage therapy, meditation
- **Negative**: no vocals, no harsh sounds, no drums, no electronic beats, no sharp transients

### Asian Spa (spa-asian)

- **Atmospheres**: zen garden, bamboo forest, temple bells, japanese onsen, lotus pond

- **Negative**: no vocals, no drums, no electronic beats

## Template File Structure

Templates are JSON files in `src/prompts/templates/`:

```json
{
  "name": "cafe-jazz",
  "description": "Cafe jazz background music",
  "outputFolder": "Cafe Jazz (flac)",
  "subGenres": ["piano trio jazz", "cool jazz"],
  "moods": ["warm", "cozy", "sophisticated"],
  "tempos": ["80-90 BPM", "90-100 BPM"],
  "instruments": ["piano", "upright bass", "brushed drums"],
  "atmospheres": ["intimate cafe", "cozy coffee shop"],
  "negativePrompts": ["no vocals", "no synths"]
}
```

Vocal templates add:
```json
{
  "vocalStyles": ["smooth female jazz vocal", "crooning male jazz vocal"],
  "lyricThemes": ["morning coffee", "rainy afternoon", "city lights"]
}
```
